# 키워드 가중치 25%포인트 간격 비교

2026-11-02. 지민의 요청에 따라 영어 검색 질의를 고정하고 키워드 가중치 0·25·50·75·100%를 비교합니다.

| 키워드 | 의미 | 처리 |
|---:|---:|---|
| 0% | 100% | 이전 B 결과 그대로 재사용 |
| 25% | 75% | 30문항 새 답변 생성 |
| 50% | 50% | 이전 C 결과 그대로 재사용 |
| 75% | 25% | 30문항 새 답변 생성 |
| 100% | 0% | 30문항 새 답변 생성; 키워드 검색만 사용하는 끝점 |

- 이전 `qa30_hybrid_20261102/retrieval.json`의 영어 번역과 의미/BM25 각 20개 후보를 그대로 사용합니다. 번역·검색·임베딩을 다시 하지 않습니다.
- `score = (1-w)/(60+dense_rank) + w/(60+keyword_rank)`, 순위는 1부터 시작합니다. 없는 쪽의 기여도는 0, w는 키워드 비중입니다. 원시 유사도의 가중 평균이 아닙니다.
- 최종 5개 청크, 한국어 원 질문, Qwen3.5-4B, 답변 프롬프트/온도/문맥/출력 제한과 출력 검증·재시도 정책은 유지합니다.
- 질문별 결과를 보고 가중치를 따로 고르지 않습니다. 모든 30문항에 동일한 각 가중치를 적용합니다.
- 새 가중치의 모든 문항에서 실제 답변 모델을 호출합니다. 이전 답변은 0%/50% 기준값에만 사용하며, 동일 가중치 작업을 중단 후 재개할 때만 해당 저장 응답을 재사용합니다.
- 기존 의미 100%의 한국어 질의 A는 번역 조건이 다르므로 가중치 비교의 0%는 영어 질의 B입니다.
- 원본·기존 임베딩·이전 실험 결과는 변경하지 않습니다. 평가용 QA 정답·영문 질문을 모델에 입력하지 않습니다.

평가 기준은 앞선 실험의 원본 기준 기대 답변과 판정 규칙을 유지합니다. 주석 영역 ID Hit@1/5, 실제 근거 충분성, 최종 답변의 정답/부분정답/오답/미답변/출력 오류를 구분합니다. 이는 동일 30문항을 사용한 설정 탐색이며 별도 검증 세트 성능이 아닙니다. 온도 0에서도 단일 실행의 생성 변동이 있을 수 있습니다.

```powershell
.\.runtime\venv-rag\Scripts\python.exe -X utf8 -u -B PM209/scripts/run_weight_sweep.py --keyword-percent 25 75 100
```

실행 후 `keyword_025`, `keyword_075`, `keyword_100`에 검색 순위와 실제 답변을 보관합니다. 원래 기본 `answer` 명령은 이 실험으로 변경하지 않습니다.
