# PM209 한국어 매뉴얼 질의·답변 평가 기준 v1

## 1. PM209 원본 질의 선정과 번역 확인

- 평가 질문은 PM209 테스트 분할 `data/test.jsonl`의 `qa_data`에서 선정한다. 문항마다 원본 QA ID, 영문 질문(`question.text`), 정답(`answer.text`), 근거 영역 ID(`answer.relevant`)를 함께 보관한다.
- 한국어 UI 시험에는 선정한 영문 질문만 한국어로 옮긴다. 질문에서 생략된 대상이나 조건도 원문 그대로 두고, 모호하면 그 사유를 기록한다. 번역에 답의 단서를 덧붙이거나 질문을 분할하지 않는다.
- 이번 실험의 입력은 매뉴얼 ID와 한국어 질문이다. 원본 정답과 정답 근거는 평가자가 참조하며, 정답 페이지나 그림을 모델에 따로 지정하지 않는다. 비교 실험에는 같은 문항 ID·매뉴얼·한국어 번역을 사용한다.
- 평가 단위는 선택한 매뉴얼, 사용자에게 보인 한국어 질문, 화면에 표시될 최종 답변 한 쌍이다. 검색된 문서 개수는 점수에 넣지 않는다.
- 원본 영문 질문과 한국어 질문의 대상·조건·알고 싶은 정보가 같은지 먼저 확인한다. 번역이 대상을 바꾸면 원래 실행은 평가 제외로 기록한다. 교정 번역의 재시험은 별도 결과로만 다룬다.
- 이전 발화나 그림 없이 “오른쪽 기호”, “이 표시”처럼 여러 대상을 가리킬 수 있고 어느 것인지 특정할 단서가 없으면 평가 제외다. 매뉴얼과 질문으로 대상을 특정하거나 질문에 직접 답하는 일반 절차가 있으면 평가한다. 여러 올바른 방법이 있다는 사실은 제외 사유가 아니다.
- 질문별로 답변을 보기 전에 무엇이 필수인지 한 줄로 적는다. 설정 경로 같은 세부사항은 그것을 모르고도 같은 답을 이해하거나 작업을 마칠 수 있으면 선택사항이다.

## 2. 정답에 필요한 내용

| 질문이 요구하는 것 | 정답에 필요한 내용 |
|---|---|
| 뜻·기능·가능 여부 | 무엇을 뜻하거나 할 수 있는지 직접 답한다. 성립 조건에 따라 결론이 달라지면 그 조건도 포함한다. |
| 조작·문제 해결 | 해당 조건에서 실행할 수 있는 매뉴얼상의 방법 한 가지. 반드시 거쳐야 하는 조작·순서·방향·안전 조건은 포함한다. 서로 독립적인 대안은 하나로 충분하다. “전체 절차”를 물으면 필수 단계를 모두 제시한다. |
| 위치·경로 | 사용자가 올바른 부품이나 화면을 찾을 수 있을 만큼 특정한다. 같은 장소에서 여러 비슷한 대상이 구분되지 않으면 구분 단서가 필요하다. |
| 수치·목록 | 해당 모델·조건의 값과 단위를 맞춘다. 범위는 양 끝, 복수 모델이면 필요한 모델별 값을 확인한다. 전체 구성이나 가능한 모드 목록을 물으면 모두, 예시나 방법 한 가지를 물으면 하나면 충분하다. |

표현·동의어·단위 환산은 허용한다. 원본 QA는 출발점이며 같은 제품 매뉴얼의 원본 페이지나 다른 절에 질문을 해결하는 답이 있으면 인정한다. OCR·그림 설명·QA가 충돌하면 원본 페이지를 우선한다. 정답 문장이 끊어져도 매뉴얼로 답과 질문 대상을 확인할 수 있으면 평가한다. 근거가 끝내 부족하면 평가 제외 사유를 남긴다.

## 3. 판정과 집계

- **정답** — 질문에 필요한 사항을 충족하고, 사용자의 판단이나 조작을 바꾸는 오류가 없다. 요청하지 않은 배경·위치의 생략, 문체·철자만의 차이는 감점하지 않는다.
- **부분정답** — 유용하고 맞는 핵심 일부를 줬지만, 필요한 단계·조건·목록이 빠져 답이 불완전하다. 추가 설명에 국소적인 사실 오류가 있으면 그 오류의 중요도를 판정 사유에 쓴다.
- **오답** — 잘못된 결론·대상·핵심 수치·조작을 제시하거나 질문을 해결할 정보를 주지 못했다. 유효한 질문에서 시스템 오류·응답 거절로 답변이 없으면 오답이다.
- **평가 제외** — 평가용 번역이 달라졌거나 질문의 대상 또는 기준 답을 확정할 수 없다. 모델이 틀렸다는 이유로 질문을 제외할 수 없다.

주 지표인 **최종 답변 정답률 = 정답 수 ÷ (정답 + 부분정답 + 오답)**. 부분정답에 임의로 반점을 주지 않는다. 전체 시도 수와 제외 수·사유도 함께 공개한다. 과거 결과와 비교할 때 공통 유효 문항에서 판정이 어떻게 바뀌었는지 따로 센다.

## 4. 다음 평가의 순서

1. PM209에서 선정한 문항 ID·제품·질문 원문·번역을 고정하고, 원본 QA와 해당 매뉴얼을 읽어 답변에 필요한 내용과 허용할 대안을 미리 적는다.
2. 최종 답변을 열어 같은 기준으로 정답·부분정답·오답 중 하나를 정한다. 기준 답안과 달라도 매뉴얼에서 다른 유효한 방법을 확인하면 페이지와 이유를 남긴다.
3. 질문 자체에 결함이 있으면 제외 사유를 남긴다. 경계 사례에 대한 이견은 원문을 함께 확인하고, 기준을 변경할 경우 버전을 구분한다.

이 파일은 기준 합의용이다. 기존 100문항의 판정 및 점수는 이전 보고서에 보존한다.
