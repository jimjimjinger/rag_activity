# PM209 30문항 검색 비교: 사전 고정 조건

2026-11-02. 같은 질문으로 번역과 키워드 검색의 영향을 분리해서 확인합니다.

| 조건 | 검색 질의 | 검색 방식 | 최종 근거 |
|---|---|---|---|
| A | 원래 한국어 질문 | 기존 의미 검색, 저장된 결과 재사용 | 상위 5개 |
| B | 질문만 영어로 번역 | 의미 검색 | 상위 5개 |
| C | B와 동일한 영어 번역 | 의미 검색 20개 + BM25 20개를 RRF로 결합 | 상위 5개 |

- 질문: `../qa30_20261102/questions.json`의 30개. 원 질문·매뉴얼 지정·본문/표/그림 각 10개를 유지합니다.
- 번역: 로컬 `qwen3.5:4b`, think=false, 온도 0, 문맥 4096, 출력 상한 256. 질문만 입력하며 정답·원 QA 영문 질문·문서 내용은 입력하지 않습니다. 기술 식별자·수치 보존을 검사하고 검색 실행 전에 번역문을 확인·고정합니다.
- 답변: 기존 `qwen3.5:4b`, 프롬프트 `pm209-grounded-ko-v1`, 문맥 8192, 출력 상한 1024, think=false, 온도 0. 원래 한국어 질문과 검색된 근거만 전달합니다.
- 의미 검색: 기존 `qwen3-embedding:0.6b` 및 전체 Qdrant 126,938개 벡터를 재사용합니다. A와 동일하게 매뉴얼 ID를 필터링합니다.
- BM25: 기존 청크의 텍스트만 SQLite FTS5에 별도 색인합니다. 영어 Porter 어간 처리, unicode61 토큰화, 검색 질의의 기본 불용어 제거, 단어/식별자를 따옴표로 감싼 OR 검색입니다. 단어 빈도·문서 길이 통계는 전체 청크 기준이고, 반환 결과는 지정 매뉴얼로 제한합니다.
- 결합: **의미 0.5 / 키워드 0.5**, `score = 0.5/(60+dense_rank) + 0.5/(60+bm25_rank)`. 순위는 1부터 시작하며 한쪽에 없으면 그쪽 기여도는 0입니다. 원시 유사도 점수의 50:50 합산이 아닙니다. 동점은 의미 검색 순위, 키워드 순위, 청크 ID 순으로 해소합니다.
- B와 C의 의미 검색 후보는 같은 한 번의 검색 결과를 공유합니다. 추가 답변 품질 재시도·가중치 탐색·프롬프트 변경·청킹 변경·재임베딩은 하지 않습니다. 기존 형식 오류 재시도 정책만 유지합니다.

## 평가

1. 자동 검색 지표: 원 QA 정답 근거 영역 ID와 검색 청크의 본문 영역 ID가 하나 이상 겹치는 `주석 영역 Hit@1`, `Hit@5`. 제목 문맥 ID는 제외합니다. 표 영역 ID가 같아도 다른 행일 수 있으므로 이는 근거의 의미적 충분성과 다릅니다.
2. 근거 충분성: 실제 LLM에 들어간 텍스트가 답변에 필요한 내용을 충분히 포함하는지 원본과 대조합니다.
3. 최종 답변: A의 원본 기준 기대 답변과 정답/부분정답/오답/미답변 판정 규칙을 그대로 적용합니다. TEXT08 등의 정답 보정 주석도 유지합니다.
4. 문항별 A→B→C의 개선·악화, 실행 시간·GPU 관측·오류·데이터 보존을 기록합니다.

30문항은 이번 비교에 사용한 진단 표본입니다. 이후 설정을 고르면 별도 미사용 질문으로 확인해야 합니다. 그림 그룹은 원 QA 근거에 그림이 포함된 분류이며, 답변 LLM이 이미지를 직접 보는 실험은 아닙니다.
