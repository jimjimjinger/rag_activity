이번 수정안은 **답변을 짧게 만드는 효과는 있었지만 전체 정답률 개선을 확인하지 못했습니다.** 두 키워드 비중 모두 이전보다 한 문항씩 낮았습니다. 30문항·1회 생성의 차이이므로 일반적인 우열로 확대하지 않고, 일반 실행의 기본 프롬프트는 이전 버전을 유지했습니다.

| 키워드 비중 | 평균 답변 길이: 이전 → 이후 | 정답으로 개선된 문항 | 정답에서 내려간 문항 |
|---|---:|---|---|
| 0% | 118.5자 → 104.5자 | 로밍 아이콘(TABLE09), 드릴 중심 맞추기(FIG01) | 점멸 횟수(TABLE08), 암호 분실(FIG06), 설치 절차(FIG07) |
| 50% | 123.5자 → 100.2자 | 입력 전압(TEXT08) | 소프트웨어 삭제(TABLE04), 로밍 아이콘(TABLE09) |

- **개선:** 50%의 입력 전압 답변에서 돌입 전류를 일반 최대 전류처럼 잘못 덧붙이는 설명이 없어졌습니다. 0%의 드릴 답변에는 빠져 있던 중심 맞추기가 포함됐습니다. 단, 해당 문장의 근거 S3를 인용 목록에서 빠뜨린 문제는 남았습니다.
- **새 오류:** 0%의 암호 분실 답변이 공장 초기화를 ‘모든 사용자 데이터 복구’ 방법처럼 설명했습니다. 원본은 초기화하면 사용자 데이터가 삭제된다고 명시합니다. 이 문항은 부분정답으로 내려갔습니다.
- **누락:** 0%의 설치 절차에서 재시작 권장을 생략했습니다. 50%의 리모컨 답변은 배터리 장착 확인을 계속 빠뜨렸습니다.
- **조건 혼합:** 50%의 소프트웨어 삭제 답변은 서로 다른 설치 파일에 해당하는 제어판 삭제와 수동 삭제를 합쳤습니다. ‘표의 조건을 보존하라’는 지시만으로 해결되지 않았습니다.
- **남은 한계:** 0%의 바구니 답변에는 중국어가 섞였고, 입력 전압·스토리지 등 일부 답변은 요청하지 않은 부연을 계속했습니다. 프롬프트 지시가 항상 준수되는 것은 아니었습니다.
- **채점상 주의:** TABLE07의 50% 답변은 충전 필요/충전 중 색상을 올바르게 구분했으나 잔량 표시 기능을 명확히 말하지 않아 부분정답으로 유지했습니다. TEXT06의 질문과 공식 정답 범위 불일치, FIG10의 원본 그림 기반 확장 기준도 이전과 동일하게 적용했습니다.

다음 개선은 모델에 전달할 근거에서 질문에 해당하는 표의 행·조건을 선별하거나, 답변의 수치·필수 조건을 근거와 대조하는 단계를 별도 실험하는 방향이 적절합니다. 이번 작업에서는 프롬프트 외 요소를 바꾸지 않았습니다.
