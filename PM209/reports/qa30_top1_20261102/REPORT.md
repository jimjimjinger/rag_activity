# PM209 Top-1 / Top-5 답변 비교

2026-11-02. 같은 질문 30개·영어 검색 질의·검색 순위를 유지한 채 **첫 번째 청크 1개만 넣어** 키워드 비중 0·25·50·75·100%의 150개 답변을 새로 생성했습니다. 이번 표본에서는 모든 가중치에서 Top-1 답변 정답 수가 Top-5보다 적었습니다. 가장 높은 조건은 두 경우 모두 키워드 0%·의미 100%였습니다.

**Top-1은 페이지 하나가 아니라 현재 청킹 결과의 청크 하나입니다.** 답변 정답률은 원본 기준 완전 정답 / 30이며 부분정답·미답변·출력 오류도 분모에 넣었습니다. 0%에도 영어 번역이 적용됩니다. 기존 한국어 의미 검색과는 다른 조건입니다.

검색 영역 Hit@1은 첫 청크의 `content_region_ids`가 주석 정답 영역 ID와 겹치는지만 확인합니다. 표 제목이나 같은 표의 다른 부분을 찾았어도 Hit가 될 수 있습니다. **76.7%의 영역 검색 성공을 76.7%의 답변 정확도라고 해석하면 안 됩니다.** 검색 순위는 이전과 같으므로 Hit@1도 이전 결과와 같습니다.

## 달라진 사례

- **TEXT08 입력 전압:** 모든 가중치에서 첫 청크는 `AC input voltage / frequency / current`라는 제목뿐입니다. 영역 Hit@1은 성공하지만 100–240VAC 수치가 없어 Top-1은 미답변입니다. Top-5는 모두 정답이었습니다.
- **TABLE02 구성품:** 키워드 0%에서 Top-5는 2위에 있던 표의 여섯 구성품을 읽어 정답이었습니다. Top-1에는 제목·확인 안내만 들어갔고 출력 형식 검사도 실패했습니다. 다른 가중치의 Top-1은 같은 제목 근거에서 미답변했습니다.
- **TABLE03 헤드셋:** 75%·100% Top-5는 각각 4위·3위의 포트 이름을 포함해 정답이었습니다. Top-1은 모든 조건에서 `Connects to a headset`만 받아 “헤드셋은 헤드셋에 연결”이라고 잘못 답했습니다.
- **TEXT06 Timeshift:** 25%·50% Top-1은 필요한 최소 1.5GB 조건만 보고 정답이었습니다. Top-5는 근거가 있어도 이 조건을 빠뜨렸습니다. 0% Top-1에는 해당 조건이 없어 부분정답입니다.
- **FIG06 SSD 암호:** 75%·100% Top-5는 소프트웨어용 128MB를 보호된 데이터 접근 가능 공간으로 오해했습니다. Top-1은 모든 가중치에서 보호 데이터와 소프트웨어 공간을 구분해 정답이었습니다.
- **FIG07 설치 절차:** 한 청크가 초기 단계 또는 `Next` 단계 하나뿐이라 전체 절차를 복원할 수 없었습니다. 기존 Top-5도 뒷단계가 부족해 부분정답이었고, Top-1에서는 제공되는 단계가 더 적습니다.

이번 결과는 필요한 내용을 1위에 모으는 문제가 남아 있음을 보여줍니다. Top-5를 유지하면서 제목만 있는 청크·표 조건과 값의 분리·절차의 연결을 점검하는 것이 다음 개선 후보입니다. 이번에는 청킹·재랭킹·프롬프트·기본 answer 설정을 변경하지 않았습니다.

## 실행·오류·보존

- 새 실행: **183.2초(약 3분 3초)**. 정상 형식 답변 119개, 근거 부족 미답변 30개, 최종 형식 오류 1개. 이후 검수·보고서 작성 시간은 제외합니다.
- 오류는 **키워드 0% TABLE02**입니다. 두 번 모두 `insufficient_evidence=true`인데 `source_ids`가 비어 있지 않아 거부됐습니다. 실패 출력 원문을 보관했고 정답으로 세지 않았습니다.
- 재시도 포함 155회 호출, 출력 총 10,636토큰, 한 시도 최대 130토큰. 종료 사유 집계 `{'stop': 155}`. 토큰 상한 잘림이나 GPU 메모리 부족은 관측되지 않았습니다.
- NVIDIA GeForce RTX 5060 Laptop GPU, VRAM 총 8,151MiB. 응답 직후 관측 사용량 3,830~3,834MiB, 온도 57~72°C. 연속 측정 최대치는 아닙니다.
- qwen3.5:4b Q4_K_M, think=false, temperature 0, 문맥 8192, 출력 1024, 동시성 1, 요청 제한 300초, 최대 2회 형식 검사 시도. 기존 한국어 질문·프롬프트와 영어 번역을 고정했습니다.
- QA 정답과 원래 영문 QA 질문은 모델에 넣지 않았습니다. 기존 Top-5의 첫 검색 청크만 사용했으며 재번역·재임베딩·DB 재검색을 하지 않았습니다. 그림 원본도 입력하지 않았습니다.

## 해석의 한계

같은 30문항으로 여러 설정을 고르는 탐색 결과이며 미사용 질문 평가나 반복 실험의 통계적 우위가 아닙니다. 기존 번역의 오류와 원본 기준 평가 보정도 그대로 유지했습니다. 경계 판정은 [문항별 사유](review.json)를 함께 확인해야 합니다.

동일한 질문·근거 메시지가 두 조건 이상에 나타난 **37개 그룹** 중 **6개**에서 문구나 상태가 달랐고, 판정 종류까지 달라진 것은 **1개**였습니다. TABLE02의 형식 오류/미답변 차이가 여기에 해당하며 둘 다 정답은 아닙니다. temperature 0이어도 완전히 같은 결과가 항상 보장되는 것은 아닙니다. 검색 근거가 같았던 조건의 출력 차이를 가중치 효과라고 해석하지 않습니다. [상세 기록](same-input-variation.json)
