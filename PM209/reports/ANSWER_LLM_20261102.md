# PM209 답변 LLM 연결 확인

2026-11-02, 기존 전체 Qdrant DB의 검색 결과를 **Qwen3.5-4B 한국어 답변**에 연결했다. 터미널 실행과 JSON 저장까지 구현했으며 채팅 화면·이미지 표시 UI는 후속 단계다. 아래 소수 질문 확인은 전체 답변 정확도 평가가 아니다.

## 실행

저장소 루트에서 실행한다. `answer`의 기본 대상은 전체 126,938개 벡터 DB이고, 선택한 매뉴얼 안에서만 검색한다.

```powershell
.\run-pm209-rag.cmd answer --manual "alienware-17-r5_users-guide_en-us" --query "이 노트북의 무게와 크기는 어떻게 되나요?"
```

프롬프트·형식·근거 검증: [answering.py](../src/answering.py). 검색 연결·저장: [rag_pipeline.py](../scripts/rag_pipeline.py)의 `answer()`. 실행 옵션은 [실행 안내](../RAG_PIPELINE.md#실행)에 있다.

## 동작과 설정

- 질문을 기존 Qwen3-Embedding-0.6B로 벡터화해 상위 5개를 검색하고, 임베딩 모델을 내린 뒤 답변 모델을 사용한다. 기존 문서 임베딩·청크·DB 적재는 반복하지 않는다.
- 답변 모델은 로컬 `qwen3.5:4b` Q4_K_M, 문맥 8,192·출력 최대 1,024토큰·temperature 0·`think=false`·요청 제한 300초다. 동시 모델 적재/요청은 1로 설정한 기존 Ollama를 사용했다.
- 입력은 사용자 질문과 검색 청크의 텍스트·유형·검수 표시·근거 ID다. 원본 QA와 이미지 바이트를 보내지 않는다. 기존 그림 description을 텍스트 근거로 사용한다.
- `answer`, `source_ids`, `insufficient_evidence`를 받고, 실제 검색 근거에 없는 ID·한국어가 아닌 답변·잘린 출력·잘못된 형식을 거부한다. 간결한 재시도는 한 번만 수행한다. 형식 통과는 의미 정확도 보증이 아니다.
- 근거가 부족하다고 반환하면 자유 생성 문장 대신 정해진 안내 문구를 표시한다. 인용한 그림의 원본 JPG·영역 ID·좌표만 `cited_figures`에 연결하며, 실제 그림을 새로 해석하거나 화면에 표시하지는 않는다.
- 결과는 `PM209/datasets/PM209/rag/full_char500_v1/answers/<UTC시각>-<고유값>.json`, 최신 결과는 같은 상위 폴더의 `last-answer.json`이다. 실패도 별도로 기록해 이전 성공 결과와 구분한다.

## 실제 질문 확인

최초 CLI 실행 두 건으로 전체 검색→GPU 생성→출처 저장을 확인했다. 이후 한국어 표현 지시를 보완한 최종 프롬프트로 **동일한 검색 결과**를 재사용해 아래 네 건을 생성했다. 아래 시간은 모델이 이미 적재된 상태의 답변 생성 호출 시간이며 검색·DB 로딩은 제외한다. [원시 응답·근거·설정 기록](answer_llm_20261102/)

| 질문 | 확인 결과 | 생성 시간 / 출력 토큰 |
| --- | --- | --- |
| Alienware 무게·크기 | 4.42kg, 높이 29.99mm·너비 424mm·깊이 332mm와 주문 구성/제조 변동 조건을 반환. 표·본문 두 근거 연결 | 2.25초 / 122 |
| Huawei 스피커의 PC 블루투스 연결 | 버튼→연결 카드→CONNECT 절차 반환. 그림·본문 두 근거와 실제 그림 1개 좌표 연결 | 1.70초 / 101 |
| 스피커 충전 케이블 연결 위치 | 충전 근거 대신 PC 연결 자료가 검색됨. 확인할 수 없다고 답함. **검색 누락 사례** | 1.38초 / 77 |
| 2026-11-02 서울 매장 판매 가격 | 매뉴얼 근거에 없어 확인할 수 없다고 답함 | 1.46초 / 82 |

최종 네 건 모두 `done_reason=stop`, 형식 재시도 0회였다. PC 연결 답변의 “단축 누름”은 여전히 어색한 번역이고, 최종 응답에서 PC 가까이에 두라는 조건이 빠졌다. 초기 무게 답변에는 제조 변동을 “제조사별 편차”로 옮긴 오류도 있었다. 한국어 지시를 보완한 최종 무게 답변에서는 개선됐지만, 자연스러운 번역과 조건 누락은 계속 검수해야 한다. 자동으로 답변을 수작업 수정하지 않았다.

최초 CLI 실측은 노트북 질문 총 64.47초(검색 준비 포함 54.68초, 모델 적재·생성 9.69초), PC 연결 질문 총 40.20초(검색 준비 포함 31.33초, 모델 적재·생성 8.77초)였다. 현재 로컬 Qdrant는 명령마다 전체 컬렉션을 메모리에 불러오는 비용이 크다. 화면 구현 시 프로세스 안에서 DB 연결을 재사용할 필요가 있다.

RTX 5060 Laptop 8,151MiB에서 생성 직후 장치 VRAM은 3,830~3,834MiB로 관측했다. Ollama가 보고한 답변 모델 VRAM은 3,214,409,726바이트이며 GPU 적재를 확인했다. 확인 시점 온도는 56~65°C였다. 연속 관측 최대치는 아니다.
