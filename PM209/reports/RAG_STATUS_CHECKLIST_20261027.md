# PM209 청킹·임베딩 작업 기록

작업일: 2026-10-26

## 1. 청킹

- 대상: 209개 매뉴얼·10,018페이지의 본문 OCR, 그림 description, 표 HTML의 셀 내용.
- 본문은 같은 페이지·제목·열의 인접 영역을 묶고, 제목·공백을 포함해 **500자 기준**으로 나눴다. 문장 경계를 우선하고, 긴 문장은 구절·단어 경계에서 분할했다.
- 이어지는 본문은 최대 **100자 겹침**을 적용했다. 그림 설명은 그림별로, 긴 표는 행·셀 기준으로 나누고 확인 가능한 헤더를 반복했다.
- 결과: **126,938개 청크**. 긴 표 문맥 26개는 길이 예외로 보존하고 검수 표시했다. 각 청크에 원본 페이지·영역 ID·좌표를 연결하고 QA 질문·정답은 제외했다.

## 2. 임베딩·저장

- **Qwen3-Embedding-0.6B**로 GPU 임베딩을 수행해 청크마다 **1,024차원 벡터**를 만들었다.
- **Qdrant 로컬 모드**에 126,938개 벡터와 청크·출처 정보를 저장했다. 검색 유사도는 코사인 방식으로 설정했다.
- 임베딩 약 90분, DB 저장 약 15분, 최종 검증 등을 포함해 **약 1시간 51분**이 걸렸다. 저장·검증 오류는 0개였다.
