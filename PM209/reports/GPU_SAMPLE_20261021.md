# PM209 그림 설명 GPU 표본 실행

실행일: 2026-10-21

RTX 5060 Laptop GPU 8GB에서 Qwen3.5-4B로 총 23개의 그림 설명을 생성했다. 전체 23,807개에 대한 종류·크기별 외삽은 약 **13.7시간**이다. 실제 작업 계획에는 중단·재시도 여유를 포함해 **15~20시간**을 잡는다. 전체 처리 완료 시간의 실측이나 통계적 신뢰구간은 아니다.

## 실행 조건

- Ollama 0.40.4, `qwen3.5:4b`, Q4_K_M.
- 모델 digest: `d8b0f5e9760cd1682034f292d7ef72ec46f432149be0df7574bf2d6e92e38c04`.
- 그림 1개씩, 긴 변 최대 1,536px, 컨텍스트 4,096토큰, 최대 출력 768토큰.
- temperature 0, 추론 모드 끄기, GPU 자동 적재, 동시 요청 1개.
- 그림과 고정 지시문만 모델에 전달했다. 본문·QA·정답 근거는 전달하지 않았다.

## 측정 방법과 시간

처음에는 train의 첫 그림 3개를 처리했다. 첫 요청은 최초 모델 로딩·초기 준비를 포함해 36.38초였다. 이후 두 그림은 0.57초와 2.07초였다. 첫 두 대상이 작은 아이콘이어서 이 세 개만으로 전체를 추정하지 않았다.

추가 20개는 train에서 그림 종류 3개와 영역 면적 3구간을 조합해 추출했다. 난수 시드는 20261021이다. 구간은 원본 영역 면적 기준으로 128²px 이하, 128²px 초과부터 512²px 이하, 512²px 초과다. 각 구간에서 2개씩 선택하고 큰 모집단 구간에 2개를 추가했다. 실제 생성은 페이지 순서로 수행했다.

각 요청의 경과 시간에서 Ollama가 보고한 모델 로딩 시간을 빼고, 같은 구간의 평균에 전체 train·val·test의 구간별 그림 수를 곱해 합산했다. 그림 자르기·JSONL 입출력·장시간 온도 변화·검수·중단·실패 재처리 비용은 이 계산에 모두 포함된 것이 아니다.

전체 분포를 반영한 그림당 평균은 약 2.08초다. 종류·크기 구간당 표본이 2~3개뿐이므로 복잡도·출력 길이 차이를 충분히 대표하지 못한다. 큰 그림이 반드시 더 오래 걸리는 것도 아니다.

## GPU와 메모리

Ollama가 보고한 모델 GPU 적재량은 약 2.92GiB였다. 약 1초 간격의 NVIDIA 관찰에서 최대 장치 전체 메모리 사용량은 3,828MiB, 최대 온도는 68도였다. 순간 최대 사용량이나 장시간 전량 실행 결과는 아니다.

## 저장과 원본 보존

실제 설명은 `../datasets/PM209/data/vlm/train.jsonl`에 저장했다. 보강본에는 train의 모든 7,004페이지와 QA 15,839개가 들어 있으며, 총 23개 그림 객체에 description이 추가됐다. 원본과 보강본을 페이지별로 대조해 description을 제외한 영역·좌표·본문·QA가 동일함을 확인했다. val·test 보강본은 생성하지 않았다.

추가 20개 중 19개를 생성한 뒤 Windows에서 길이 261자의 이미지 경로를 읽지 못해 중단됐다. 완료한 결과를 보존하고, 이미지 파일을 여는 순간에 Windows 확장 경로를 사용하도록 수정했다. 재실행에서 기존 19개를 재사용하고 남은 1개를 처리했다. 원본의 image_filename은 바꾸지 않았다.

## 설명 품질에서 확인한 한계

- 경고 아이콘 2개는 삼각형·색상·느낌표를 설명했다.
- 스마트폰 내부 그림에서는 A15 Bionic과 부품 배치를 설명했지만, 작은 배터리 표기에서 확인하기 어려운 모델 번호와 주의 문구를 단정하는 문제가 있었다.
- Mode switch 그림에서는 작은 기호를 on/off 의미로 추측했다. 원본에서 그 의미가 확실하지 않은 경우 이를 검색 사실로 신뢰하면 안 된다.
- 속도 측정은 설명 정확도 평가가 아니다. 전체 그림 설명을 검수하거나 정량 정확도를 측정한 결과는 아니다.
